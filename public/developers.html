Use our nakamal map in your website or app

Killim Light shows which nakamals in Vanuatu have kava ready, live, set by the owners themselves. The map and the data are open: tourism sites, news sites, other Vanuatu apps and anyone else can show them for free, as long as they credit Killim Light.

Quick start

Show the live map on your page:

<iframe src="https://killimlightvanuatu.com/embed?lang=en" width="100%" height="420" style="border:0" title="Nakamal map"></iframe>

Or get the data in your own code:

const { nakamals } = await (await fetch('https://killimlightvanuatu.com/api/v1/nakamals')).json();

No key, no sign-up, free. Just credit “Nakamal data: Killim Light”.

1. Embed the live map

Paste this where you want the map. It updates itself every minute.

<iframe src="https://killimlightvanuatu.com/embed?region=efate&lang=en"
        width="100%" height="420" style="border:0;border-radius:12px"
        loading="lazy" title="Killim Light: live nakamal map"></iframe>
OptionValues
regionefate (default), santo, tanna, all
langbi Bislama (default) or en English
lat, lng, zoomStart the map on one spot, e.g. a hotel
lightgreen to show only nakamals with kava ready

2. Get the data (API)

No key or sign-up needed. Works from any website (CORS is open) and any app. Please don't request more than once a minute per user; the data is cached for 30 seconds anyway.

AddressWhat you get
GET /api/v1/nakamalsJSON list of every nakamal on the map with its light right now
GET /api/v1/nakamals.geojsonThe same as GeoJSON, ready for Leaflet, Mapbox, Google Maps, QGIS or ArcGIS
GET /api/v1/nakamals/<id>One nakamal
?region=santo, ?light=greenFilters you can add to the list and GeoJSON

Example: one nakamal

{
  "id": "salo",
  "name": "Salo",
  "area": "Beverly Hills",
  "region": "efate",
  "lat": -17.721762, "lng": 168.325115,
  "status": "green",            // green | amber | closed | stale | reported
  "light": "green",             // what the owner set
  "lightUpdatedAt": "2026-10-20T07:12:00.000Z",
  "closeTime": "23:00",         // Vanuatu time; the light closes itself then
  "note": "Fresh Pentecost kava tonight",
  "kava": { "from": "Pentecost", "strength": "strong" },
  "prices": [{ "item": "Big shell", "price": "150 VT" }],
  "rating": { "average": 4.6, "count": 12 },
  "photos": ["https://killimlightvanuatu.com/img/photo/salo/p….jpg"],
  "url": "https://killimlightvanuatu.com/n/salo"
}

Use status to colour your pins. stale means the owner hasn't updated the light in 14 hours; reported means several customers said the light is wrong in the last 3 hours.

3. Examples

Show nakamals with kava ready, in plain JavaScript

const res = await fetch('https://killimlightvanuatu.com/api/v1/nakamals?light=green');
const { nakamals } = await res.json();
nakamals.forEach(n => console.log(n.name, n.area, n.url));

Add the pins to your own Leaflet map

const colours = { green: '#1d7a45', amber: '#a85f00', closed: '#b5382a', stale: '#7d7466', reported: '#7d7466' };
fetch('https://killimlightvanuatu.com/api/v1/nakamals.geojson')
  .then(r => r.json())
  .then(data => L.geoJSON(data, {
    pointToLayer: (f, latlng) => L.circleMarker(latlng, { radius: 8, color: '#fff', weight: 2, fillOpacity: 1, fillColor: colours[f.properties.status] }),
    onEachFeature: (f, layer) => layer.bindPopup(`<b>${f.properties.name}</b><br>${f.properties.status}`),
  }).addTo(map));

Google Maps

map.data.loadGeoJson('https://killimlightvanuatu.com/api/v1/nakamals.geojson');

Versions, limits and uptime

  • Version 1 lives at /api/v1/. We won't remove or rename fields in v1; new fields may be added, so ignore ones you don't know. Breaking changes would get a new /api/v2/, announced here first.
  • Limits: the data refreshes every 30 seconds, so there's no need to ask more than once a minute per user. For server-side jobs, cache the response for at least 30 seconds. If you expect more than 10,000 requests a day, tell us first.
  • Errors: an unknown nakamal id returns 404 with {"error": "Not found"}. Anything else non-200 means try again in a minute.
  • Times are ISO 8601 in UTC; Vanuatu is UTC+11 all year. closeTime is local Vanuatu time.
